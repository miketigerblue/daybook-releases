# Daybook releases

Downloads and the update feed for **Daybook**, a macOS menu bar app by Tiger Blue that turns the screenshots you already take into searchable, summarised lab notes.

- Disk images are attached to the [releases](https://github.com/miketigerblue/daybook-releases/releases).
- `appcast.xml` is the feed the app reads to find updates. Every update is signed, and the app verifies the signature before installing.

Daybook is signed with a Developer ID and notarised by Apple. It needs macOS 15 or later.

This repository holds releases only. It contains no source code.
